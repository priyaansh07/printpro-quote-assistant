# PrintPro Quote Follow-up Assistant

Clickable prototype for a fictional B2B packaging company, PrintPro Packaging, Ahmedabad.
Group 9 – Vanshi Varia, Diya Shah, Tanisha Jethva | CIA 3, Low-Code Tools | All data fictional.

**Live site:** https://priyaansh07.github.io/printpro-quote-assistant/

It shows which quotations need a follow-up, lets a simulated AI agent draft the e-mail, checks every draft with a guardrail, stops reminders when the customer replies or the deal is Won/Lost/Expired, and sends any discount request above 8% to the Sales Head for approval.

Everything runs in the browser on mock data: no login, no backend, nothing is really sent. Refreshing the page resets the demo.

## Files

- `docs/index.html` – the live site (served by GitHub Pages)
- `PrintPro-Quote-Assistant.html` – the same app as a single file to open offline
- `PrintPro-QR.png` / `PrintPro-QR.svg` – QR code that opens the live site
